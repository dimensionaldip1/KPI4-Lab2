Core UI Elements and Their Purpose

1. Radiobutton


Purpose: Allows the user to select only one option from a group choices.

2. Checkbox


Purpose: Used to select one or multiple options.

3. Text Input

Purpose: Allows the user to input a single line of text.

4. Tabs

Content for Tab 1
Content for Tab 2

Purpose: Organizes content into logical groups within the same view to save screen space.

5. Button

Purpose: Triggers an immediate action or event.

6. Text Label

Purpose: Displays read-only text.

7. Link

Go to Google

Purpose: Enables navigation to another web page, an external resource, or a specific section within the page.

8. Tooltip

Hover over me! Contextual tip

Purpose: Displayscontextual information when the user hovers over an element.

9. Dropdown List

Purpose: Allows selecting a single item from a collapsible list to save vertical layout space.
